# 知账

> 一个纯本地的安卓记账 App —— 数据只存在你手机里，不联网、不上传、不注册。

## 这是什么

知账是一个个人记账工具。它的主张很简单：**你的钱花在哪儿，是你自己的事。**

所以它：

- **不联网** —— 没有服务器，没有账号，没有埋点
- **不上传** —— 所有数据存在手机本地的 SQLite 数据库里
- **不需要注册** —— 装上就能用

## 功能

### 记账

- **手动记账**：输金额、选分类、写备注，三秒一笔
- **自动记账**：通过系统通知监听，自动抓取支付宝 / 微信 / 云闪付的支付记录，并自动猜测分类

### 看账

- **账单列表**：点开可改分类、可删除
- **统计页**：环形图看占比 + 分类明细，可翻月份

### 自检与调试

- **自动记账体检**：监听服务断开时主动提示，点一下即可修复
- **通知侦察页**：查看抓到的原始通知，以及监听服务的连接 / 断开记录

## 自动记账是怎么工作的

```
支付宝 / 微信 完成支付
        ↓
系统弹出支付通知
        ↓
PaymentNotificationListener 收到通知
   （前提：用户已手动授予「通知使用权」）
        ↓
PaymentParser 用正则提取金额，并排除退款、收款等非支出项
        ↓
AutoCategory 按关键词猜测分类
        ↓
写入本地数据库
```

监听服务由系统托管，**不需要 App 常驻前台，从最近任务划掉也不影响**。

### 已知限制

- 只能捕捉**会弹出通知**的消费。通知被关闭、内容被隐藏，或本身不弹通知的扣费场景无法捕捉
- 金额识别可靠，但商户名不一定出现在通知里，因此分类有时会落到「其他」
- 国产系统的后台管理会杀死监听服务，需要手动配置自启动与后台白名单
- 微信聊天消息若包含金额格式，可能被误判为支出（待修复）

## 使用须知

安装后**自动记账不会立即生效**，需要手动开启权限：

1. 打开知账，点击首页的橘色提示条
2. 在系统设置中找到「知账」，打开「通知使用权」
3. 建议同时配置：自启动、允许完全后台行为、在最近任务中加锁

## 技术栈

|          |                                                    |
| -------- | -------------------------------------------------- |
| 语言     | Kotlin                                             |
| 界面     | XML 布局                                           |
| 数据库   | Room                                               |
| 图表     | 自绘（`DonutChartView`，基于 `Canvas.drawArc`）      |
| 最低支持 | Android 8.0（API 26）                               |
| 构建     | Gradle 7.2 + Android Gradle Plugin 7.1.2           |

> **关于工具链**：本项目使用 Android Studio 2021.1 + AGP 7.1.2 + Kotlin 1.5.30，`compileSdk` 为 30。因开发环境锁定在该版本，未采用 Jetpack Compose，而使用传统 XML 布局。环形图亦未引入任何第三方图表库。

## 项目结构

```
app/src/main/java/com/example/myledger/
├── MainActivity.kt                        记账主页（含自动记账体检）
├── StatsActivity.kt                       统计页
├── DebugActivity.kt                       通知侦察页
├── ExpenseAdapter.kt                      账单列表适配器
├── DonutChartView.kt                      自绘环形图
├── data/                                  数据层
│   ├── Expense.kt                         账单实体
│   ├── ExpenseDao.kt                      数据库操作
│   ├── AppDatabase.kt                     数据库本体
│   ├── Categories.kt                      分类清单 + 配色
│   ├── CategorySum.kt                     统计聚合结果
│   └── AutoCategory.kt                    从通知文本猜测分类
└── notify/                                自动记账
    ├── PaymentNotificationListener.kt     通知监听服务
    ├── PaymentParser.kt                   从通知中提取金额
    └── NotificationLog.kt                 原始通知日志（调试用）
```
